# FD1791

`FD1791` jest wspólnym rdzeniem logicznym rodziny FD179x. `FD1793` dziedziczy
po nim i zmienia wyłącznie właściwość elektrycznej magistrali DAL na `True`.

## Zakres

- [x] Rejestry command/status, track, sector i data.
- [x] Polecenia Type I–IV, transfery sektorów, błędy i `INTRQ`/`DRQ`.
- [x] Wspólny kontrakt `IFD1791DiskImage` oraz opcjonalne strony dysku.
- [x] Jawne kodowanie i dekodowanie magistrali przez `Fd179xDataBusMode`.
- [x] Kompatybilność `IFD1793DiskImage` jako interfejsu pochodnego.
- [x] Testy kontraktu bazowego, dziedziczenia i wszystkich 256 wartości bajtu.
- [x] Kaypro-specificzne wybieranie napędu, strony, WAIT i agregacja `DRQ`/`INTRQ`
      są realizowane przez `KayproFdcWiring`, nie przez kontroler.

## Polaryzacja magistrali

API rejestrów `Read`/`Write` operuje na wartościach logicznych. Adapter sprzętowy
powinien używać `EncodeDataBus` przy wyjściu i `DecodeDataBus` przy wejściu:

- FD1791: `Inverted` — DAL jest odwrócone;
- FD1793: `True` — DAL jest nieodwrócone.

Nie należy odwracać istniejącego API rejestrów globalnie, ponieważ zmieniłoby to
zachowanie emulacji i istniejących map magistrali.
