# I8272 — kontroler dyskietek CPC

`lib/PetEmulator.CpcFdc/I8272Chip.cs` modeluje kontroler używany przez CPC6128. Maszyna mapuje
rejestr statusu pod `FB7E`, rejestr danych pod `FB7F`, a sterowanie silnikiem pod `FA7E`.

Kontrakt obejmuje komendy odczytu/zapisu sektora, geometrię DSK, status transferu, przerwanie,
reset oraz `CaptureState/RestoreState`. Snapshot kontrolera zawiera również stan obu napędów,
w tym obraz DSK, pozycję głowicy, silnik i ochronę zapisu.

Nie jest to wspólny kontrakt z FD179x używanym przez TRS-80 i Kaypro: format DSK oraz protokół
I8272 pozostają specyficzne dla CPC.
